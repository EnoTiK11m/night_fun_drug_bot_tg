# Конфигурация

[README](../README.md) · [Команды](COMMANDS.md) · [Production](PRODUCTION.md)

Источник defaults и проверки — [app/config.py](../app/config.py).
[.env.example](../.env.example) содержит все поддерживаемые параметры, но его
демонстрационные значения credentials и администратора не являются defaults.
Создайте `.env` и задайте свои credentials. Переменные процесса имеют приоритет
над `.env` (`load_dotenv` не включает override). Изменения применяются после запуска нового процесса.

Обязательны только `BOT_TOKEN`, `API_USER_ID`, `API_KEY`; отсутствие или пустое
значение отклоняется при startup. Формат credentials здесь не проверяется —
действительность устанавливает внешний сервис.

Числовые поля требуют целого числа, если явно не указано «число».
Ошибка преобразования добавляет ошибку конфигурации, даже если временно используется default.
«Ограничивается» означает clamp без ошибки за выход за диапазон.
Bounded floats дополнительно требуют конечного числа; обычные float-поля такого
явного валидатора не имеют. Используйте конечные числовые значения.
Boolean принимает `1/true/yes/y/on` или `0/false/no/n/off` без учёта регистра;
прочие значения — ошибка конфигурации. ID-списки принимают целые числа через
запятую или `;`, пробелы и пустые элементы пропускаются; иной элемент — ошибка.
Время указано в секундах, если в имени или описании не заданы другие единицы.

## Access/admin

| Переменная | Required | Default | Range / validation | Назначение |
| --- | --- | --- | --- | --- |
| `ADMIN_USER_IDS` | нет | пусто | Список целых ID | Telegram user ID администраторов через запятую |
| `ALLOWED_USER_IDS` | нет | пусто | Список целых ID | Разрешённые пользователи личных чатов через запятую |
| `ALLOWED_CHAT_IDS` | нет | пусто | Список целых ID | Разрешённые Telegram chat ID через запятую |
| `ALLOW_GROUP_CHATS` | нет | `false` | Boolean | Разрешить работу в группах |

Порядок access gate важен: администратор разрешён всегда; затем чат из
`ALLOWED_CHAT_IDS` разрешён независимо от остальных ограничений. После этого
непустой `ALLOWED_USER_IDS` ограничивает пользователей, а для group/supergroup/channel
проверяется `ALLOW_GROUP_CHATS`. В остальных чатах доступ разрешён.
Следовательно, `ALLOWED_CHAT_IDS` — явное разрешение, а не дополнительный фильтр.
При пустых списках все личные чаты открыты, группы запрещены по умолчанию.
Административные права задаёт только `ADMIN_USER_IDS`; для части команд нужен личный чат.
Не публикуйте реальные ID в примерах или репозитории.

## Фиксированные политики

Rule34 post API и autocomplete URLs заданы в коде, не ENV-переменными.
HTTP 403 backoff, один half-open probe, период claim renewal и heartbeat также
не имеют отдельных ENV-настроек. Подробности: [Observability](observability.md).
SQLite WAL, foreign keys и busy timeout устанавливаются connection layer;
не приписывайте им несуществующие параметры конфигурации.

Переводы тегов кэшируются в SQLite. Для отсутствующих переводов фоновая задача
передаёт Google Translate только имена тегов, без user ID и медиа.
Если сервис недоступен или перевод отключён, исходные английские теги, поиск,
blacklist и подписки сохраняются.

Trace может содержать текст запроса, даже после маскировки известных секретов.
Ротация и privacy: [Observability](observability.md#trace-writer-security-and-lifecycle).
